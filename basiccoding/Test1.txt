 2. Differentiate between =, ==, and is.

Answer:
= assigns a value to a variable. 
== checks whether two values are equal. 
is checks whether two variables refer to the same object in memory.

Example:
x = 10
x == 10      # True
x is 10      # checks object identity

7. Explain mutable vs immutable objects with two examples of each.

Answer:
Mutable objects can be changed after they are created. 
Examples: list, dictionary.

Immutable objects cannot be changed after they are created. 
Examples: string, tuple.

Answer:
A list is mutable, so its elements can be changed. A tuple is immutable, so its elements cannot be changed.

9. What is printed? Explain the reason.
a = [1, 2, 3]
b = a
b.append(4)
print(a)
print(b)

Output:

[1, 2, 3, 4]
[1, 2, 3, 4]

Explanation: a and b refer to the same list object. Therefore, when b.append(4) changes the list, the change is visible through a too.

🧠 Remember:

b = a

does not create a copy of the list.
